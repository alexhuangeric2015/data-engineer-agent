# 领导汇报页构图

同一页已经确认的文字只重排。主视觉要回答标题里的问题。

## 何时使用

- 重做规划汇报中的单页，素材只来自该页标题、条目、页脚和备注
- 现稿是等宽分栏、等高色条，或结论只写在页脚、备注
- 需要单独出样稿，用来对照另一版页面

## 不要使用

- 用汇报页替代独立架构全景
- 这一页还没有确认文字
- 任务是改已经定稿的同一个文件

## 先选一种主结构

读标题在问什么，只选一种，不沿用上一页的图型：

- 归属或包含：外框套内卡，同级对象并排，当前和规划做成对象上的标签
- 路径或消费：按原文顺序从左到右；缺一步就单独成组
- 对照：左右两组，不拆成三份相同清单

图标只帮助识别对象。边长不超过所在卡片短边的三分之一，不把立体装饰放在画面中央。

## 页面五层

1. 标题层：主题词、橙色短下划线、一句判断。判断取自该页标题或备注，不写章节号。
2. 主结构：面积最大，表达上面选定的论证。
3. 支撑组：其余原文放进白卡片。各组内部结构可以不同，不复制成同样的色条。
4. 底部落点：页脚若是并列去处，就并列摆开，不加箭头；原文若是顺序，才编号并加箭头。不把主结构原文再抄一遍。
5. 边界行：画面可能被看成部署图、新建系统或已经投产时，用备注里的原句写明不表达什么。

## 文字边界

- 卡片上的词必须能在该页原文或该页已附的架构口径里找到
- 不补收益数字、客户名、产品名、SQL 或运行机制
- 当前和规划标在对象上，不只留在备注
- 内部能力放在所属对象里面，不和同级对象排成同一级

## 视觉

- 浅蓝画布，白卡片，深蓝标题，蓝色强调；橙色只用于标题短线
- 图形用原生形状，整页不贴生成图片
- 标题不低于 26 磅，卡片标题不低于 13 磅，说明不低于 11 磅
- 卡片内边距不小于 0.12 英寸；文字不压图标，不溢出卡片

## 交付

样稿放在独立目录，同时给出可编辑 pptx 和预览 png。不改已有正稿页、总文件和原生成脚本。

## 做完自检

- 遮住备注，仍能看出归属、当前或规划，以及这页不承诺什么
- 各组卡片的内部结构不相同
- 任何一个新增词都能指回该页原文

## 常见走样

| 现象 | 处理 |
| --- | --- |
| 等宽色带 | 改成包含、路径或对照 |
| 结论只在页脚 | 提到副标题或对象标签 |
| 内部能力与主体并列 | 放进主体卡片内部 |
| 并列落点画成箭头流程 | 去掉箭头，改回并列 |
| 为填空补一句解释 | 删掉，或改用原文里已有的词 |
