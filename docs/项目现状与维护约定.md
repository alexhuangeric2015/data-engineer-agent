## 当前项目定位

项目基于火山 HiAgent 建设数据资源智能体，面向治理后的表结构、字段、数据字典类型及码值，提供自然语言查询和连续追问。当前采用对话型单 Agent，未采用对话流型或流程编排型应用。

HiAgent 应用独立运行，与本仓库其他应用代码没有已确认的运行联系。本地文档、加工材料及校验结果不能作为平台已经部署、模型已遵循规则或性能已验收的证据。

## 查询与数据语义

- 新目标先通过对应知识库定位候选与标识，再实际查询数据库核验和取数；有效上下文可以复用，歧义对象由用户确认。不能用知识库片段或模型记忆代替资产事实核验。
- 关联查询按“表 → 字段 → 字典类型 → 码值”推进，不确定父对象时不擅自选取下层对象。
- `table_schema` 字段：`table_name_en`、`table_name_cn`、`column_name`、`column_cn_name`、`column_type`、`is_key`、`is_related`、`related_column_en`、`related_column_cn`、`biz_desc`。
- `data_asset_code_kb` 字段：`code_table_cn_name`、`code_table_en_name`、`code_value`、`code_desc`。
- `related_column_en`、`related_column_cn` 表示字段关联的代码英文名称、中文名称，与字典类型英文、中文名称对应核验，不是已经确认的物理外键关系。
- 原码值按字符串保留前导零、大小写及原始描述；重复记录和同码异义不静默合并。缺失信息不编造，截断结果不称为完整结果。
- 更完整的运行约束、版本历史及实测边界见 [HiAgent运行说明](agent-prompt/HiAgent运行说明.md)。其中历史版本记录不能覆盖本文或用户最新确认。
