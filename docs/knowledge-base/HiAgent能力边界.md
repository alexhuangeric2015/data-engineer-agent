# HiAgent 能力边界

本文档供 HiAgent 知识库导入。它只回答三件事：HiAgent 能做什么、不能做什么、能力停在哪里。

依据分两层，回答时要标明来自哪一层：

- 产品页表述：火山引擎 HiAgent 产品页，https://www.volcengine.com/product/hiagent 。其中的模板数量、插件数量、渠道名称描述产品定位，具体以当前租户开通的版本为准。
- 公开接口：火山引擎官方仓库 volcengine/hiagent-python-sdk 的 main 分支。知识库 Query 的版本号是 2023-08-01，评测接口的版本号是 2025-02-01。接口里没有的动作，不能说成 HiAgent 已经提供。

HiAgent 是企业级智能体工作站，负责应用入口、会话、知识检索、已发布插件和工作流的调用、评测与观测。数仓、调度、元数据、指标平台和代码仓库仍由那些系统自己负责。

## 平台定位

### HiAgent 是什么

适用问法：HiAgent 是什么、智能体工作站、1+N+X、和扣子有什么区别、产品定位。

HiAgent 是火山引擎的企业级智能体工作站。产品页把它概括为「1+N+X」：统一入口、一批可复用的场景能力、以及业务侧按需搭建的长尾应用。

产品页写明的搭建材料是：提示词、插件、MCP、知识库、工作流，并提供企业场景模板。产品页写明的发布方式是：飞书、钉钉、微信等 IM，以及 API、WebSDK，用于接入企业已有系统。

公开 Python SDK 把平台调用分成这些服务：

- 对话服务：面向一个已发布应用，用应用密钥创建会话并收发消息。
- 知识库服务：按工作空间和知识库 ID 检索片段。
- 插件服务：读取并执行已经归档的插件。
- 工作流服务：读取、同步运行、异步运行已发布工作流，并查询运行状态。
- 评测服务：管理评测任务、规则集和评测报告。
- 观测服务：签发观测令牌、查询 Trace，并对 Trace 或告警做分析。
- 上传服务：上传、转长效、下载、删除文件。

完成标准：能用一句话说明 HiAgent 管的是智能体应用生命周期，并指出上面哪一个服务承担当前问题。

### 在本项目中 HiAgent 和其他组件如何分工

适用问法：HiAgent 和 AgentScope、知识库、Skill、MCP 谁负责什么、能力分工。

本项目把数据开发智能体拆成五块，各管一段：

- HiAgent 提供应用入口、会话、知识库、已发布插件和工作流的运行环境。
- AgentScope 编排智能体、工具、上下文和工作流。它不代替企业数据平台。
- 知识库保存可检索的文档片段。它不执行外部系统操作。
- Skill 保存任务步骤、约束和交付格式。它不保存动态业务数据，也不保存系统凭证。
- MCP 连接元数据、数仓、调度、代码仓库和质量平台。它不决定审批策略。

数据口径、表字段、调度任务和 SQL 是否正确，由对应的企业系统和 Skill 判断。HiAgent 负责把这些材料接进会话，并按应用配置去检索或调用。

完成标准：一件事情能被归到唯一的负责组件；归不到 HiAgent 的动作，不写成 HiAgent 的内置能力。

## HiAgent 能做什么

### 调用一个已经发布的智能体应用

适用问法：HiAgent 能搭建应用吗、app key、会话入口、发布渠道、开场白。

调用一个应用前，这个应用已经在 HiAgent 中发布，并且调用方持有该应用的 app key。对话服务可以：

- 读取应用配置预览和开场配置。
- 创建、列出、更新、删除、置顶会话。
- 以阻塞或流式方式发送消息，重新生成、继续生成、停止生成、清空消息。
- 读取历史消息，提交反馈，标记某条回答已被采用，获取推荐问题。
- 读取和设置应用用户变量、会话输入。

产品页说明应用可以发布到飞书、钉钉、微信、API 和 WebSDK。某个渠道是否可用，以该应用实际发布的渠道为准。

运行中的流式事件可以包含这些阶段：模型消息、思考消息、知识检索、问答库检索、术语库检索、知识图谱检索、长期记忆检索、插件调用、智能体意图、智能体跳转和接管、深度检索、工作流开始和结束、Token 消耗。某次会话只会出现该应用已经配置的阶段。

完成标准：说明当前调用的是哪一个已发布应用；没有 app key 时，停止声称已经连上 HiAgent 应用。

### 检索知识库、问答库和术语库

适用问法：知识库检索、问答库、术语库、语义检索、全文检索、混合检索、TopK、相似度阈值。

知识库服务公开的动作是 Query，也就是检索。请求要带工作空间 ID、知识库 ID 列表和关键词。

检索类型 Type 只有三种：

- 1：知识库。
- 2：问答库。
- 3：术语库。

检索方法 RetrievalSearchMethod 只有三种：

- 0：语义检索。
- 1：全文检索。
- 2：混合检索。

默认返回 5 条，默认分数阈值 0.5。可以指定 rerank 模型。上下文膨胀默认关闭；打开后膨胀系数默认 1，最大 3。

每条结果包含：知识库 ID 和名称、文档 ID 和名称、分段 ID、分段正文、得分。

对话流里的知识检索、问答召回、术语召回、知识图谱召回，表示这个应用在运行时配置了对应能力。没有配置的应用不会产生这些事件。

完成标准：回答引用文档名、分段 ID 和得分；三类库和三种检索方法使用上面的编号，不互相替代。

### 调用已经归档的插件

适用问法：插件、工具、MCP、ExecArchivedTool、自定义 API、HiAgent 能不能调外部系统。

插件服务能做两件事：按工作空间 ID 和插件 ID 读取已归档插件，以及执行这个已归档插件。

产品页写明平台提供插件、MCP，并允许把工作流发布成 MCP。插件背后可以是内置能力或企业自己登记的 API。执行结果来自该插件所连接的系统，不是 HiAgent 自己算出的业务数据。

一个插件能被当前会话调用，需要同时满足：插件已归档、当前应用已经绑定它、调用参数符合该插件的定义。

完成标准：指出插件 ID 和它连接的外部系统；没有绑定记录时，把该外部动作标为当前应用不可用。

### 运行已经发布的工作流

适用问法：工作流、流程编排、同步运行、异步运行、人工确认、中断、恢复运行。

工作流服务可以读取工作流定义。运行一个工作流需要该应用的 app key。运行方式有两种：同步运行，以及异步运行后用运行记录查询状态。

工作流可以在中途中断。中断之后通过恢复接口继续，恢复同样分为阻塞和流式。流式事件里会出现流程开始、中断、结束、失败和费用。

产品页说明工作流用可视化方式编排知识库、插件、模型和代码等节点。节点实际能做什么，等于这个已发布流程里已经放下的节点，不等于 HiAgent 临时拥有全部外部系统的权限。

完成标准：说明运行的是哪一个已发布工作流、同步还是异步、当前状态是进行中、中断、结束还是失败。

### 使用这个应用自己的长期记忆

适用问法：长期记忆、记忆、跨会话、清记忆、HiAgent 记不记得。

对话服务可以列出、更新、删除、清空当前应用的长期记忆，运行时也可以出现长期记忆检索事件。

这是该应用内的记忆条目。它跟随着应用和用户变量，不代替知识库文档，也不代替数仓里的历史数据。清空之后，后续检索不再把这些条目当作仍可引用的记忆。

完成标准：说明记忆属于哪一个应用；需要事实数据时改走知识库或外部系统，不把长期记忆说成企业数据库。

### 对智能体做评测

适用问法：评测、评测集、评测报告、规则集、效果评估、HiAgent 能不能自动变聪明。

评测服务可以创建、查看、更新、暂停、重试、删除评测任务；可以读取评测集的列和用例；可以提交一组推理结果；可以创建和列出评测规则集；可以获取评测报告。

评测回答的是：在给定数据集和规则下，这次任务表现如何。报告生成之后，提示词、知识库、插件和工作流保持原样，直到有人单独发布变更。

完成标准：区分评测报告和线上配置。报告里的分数不自动变成新的应用版本。

### 观测一次调用的链路和消耗

适用问法：观测、Trace、Span、延迟、Token、告警分析、排障。

观测服务可以：

- 用工作空间 ID 和自定义应用 ID 签发 API Token。
- 按工作空间分页列出 Trace Span。排序字段可以是开始时间、耗时、首包耗时、总 Token。
- 对一个或多个 Trace 发起分析，并查询分析历史。
- 对一条告警规则发起分析。

查询观测需要火山引擎访问密钥。Span 上可以使用 Trace ID、Span ID、状态码、状态说明、开始和结束时间来定位一次调用。

观测告诉你这次智能体调用慢在哪里、失败在哪里、用了多少 Token。业务库的数据是否算错，仍要回到产生那份数据的系统里核对。

完成标准：观测结论绑定 Trace ID 或告警规则 ID，并写明它解释的是智能体调用，还是业务数据本身。

### 上传、下载和删除平台文件

适用问法：上传文件、下载文件、文件过期、长效存储、附件。

上传服务可以：

- 按文件 ID 整文件上传，可选内容类型和过期时间，过期时间的写法如 15h。返回路径、SHA256 和字节大小。
- 把文件转为长效存储。
- 申请下载钥匙并下载到本地路径。
- 按文件 ID 和 SHA256 删除文件。

这个服务管理的是平台里的文件对象。文件进入知识库索引、成为某个应用可检索的分段，是知识库管理上的另一步。

完成标准：区分「文件已上传」和「知识库已可检索」。只完成上传时，不声称问答已经能命中该文件。

## HiAgent 不能做什么

### 知识库不能充当数仓、指标平台或元数据平台

适用问法：HiAgent 能不能查数、跑 SQL、看血缘、改调度、发布任务、代替数据平台。

知识库 Query 返回的是文档分段，不是 SQL 结果，也不是表的实时行数。公开的知识库服务没有建表、执行 SQL、查询血缘、发布调度、合并代码这些动作。

要读取或变更企业数据平台，当前应用必须已经绑定对应的插件、MCP 或工作流，并且该插件真正连接到那个平台。连接不存在时，HiAgent 给不出该平台的实时结果。

指标口径、字段含义、任务依赖如果没有被写进知识库、问答库、术语库，或者没有被插件返回，HiAgent 不会因为「它是智能体平台」就自动知道。

完成标准：数据平台上的实时事实只来自已接通的插件或工作流；没有接通时，明确说当前应用没有这条能力。

### 未发布、未绑定的对象不能被当前会话使用

适用问法：没配知识库、插件找不到、工作流没发布、app key、权限不够。

当前会话的边界就是这一个 app key 所代表的应用。下面这些对象对这次会话不可用：

- 还没有发布的应用。
- 没有绑到这个应用上的知识库、问答库、术语库。
- 没有归档，或没有绑到这个应用上的插件。
- 没有发布、或这次调用没有 app key 的工作流。
- 其他工作空间里的数据。知识库检索必须带工作空间 ID。

OAuth 同样停在应用配置上。对话服务可以查询 OAuth 令牌和某条消息的授权状态；授权没有完成时，依赖该外部账号的工具不可用。

完成标准：先确认应用、工作空间和绑定关系，再描述这次会话实际拥有的知识库、插件和工作流。

### 评测、观测和分析不会自动修改线上应用

适用问法：自动优化、越用越聪明、观测能不能自己修、评测完会不会自动发布。

评测服务停在任务、数据集、规则集和报告。观测服务停在令牌、Trace 和分析结果。分析可以解释一条 Trace 或一条告警，接口本身不发布新版本，不改提示词，不改知识库分段，不重跑业务调度。

产品页把开发、评测、发布、观测描述为一条生命周期。从报告或 Trace 到修改线上配置，中间仍要有人完成编辑和发布。

完成标准：把「看到问题」和「已经修复上线」分成两件事。只有发布动作发生之后，才说线上行为改变了。

### 上传文件、清空记忆都不等于更新了知识库

适用问法：传了文档为什么搜不到、删除文件、清空记忆、知识库有没有更新。

上传服务和知识库检索是两条链路。上传成功只说明文件对象存在；检索能命中，才说明对应知识库已经包含可召回的分段。

删除上传文件，删除的是该文件 ID。它不会自动删除某个知识库分段，除非知识库管理侧也做了删除。

清空长期记忆，清空的是这个应用的记忆条目。知识库、问答库、术语库里的文档还在。

完成标准：回答「能不能搜到」时，依据检索结果里的文档名和分段 ID，不依据文件曾经被上传过。

## 能力停在哪里

### 一次检索的结果停在命中的分段

适用问法：检索不到、分数阈值、TopK、引用、幻觉、知识库准不准。

一次 Query 的全部证据就是返回的那些分段。默认最多看 5 条，得分低于 0.5 的分段默认不返回。膨胀最多再扩 3 倍上下文，扩的仍是相邻分段，不是整份文档，更不是整个知识库。

结果为空表示这次关键词、库类型、检索方法和阈值下没有命中。它不证明企业里不存在这份知识，也不证明业务事实为假。

命中的正文是分段内容。用分段回答时，带上文档名、分段 ID 和得分。分段没有写到的数字、表名、口径，不从模型常识里补成知识库结论。

问答库、术语库、知识库要分库检索。一个库没命中，不等于另两个库也没有。

完成标准：每条知识库结论都能指回一个分段；没有分段时，结论写成「这次检索未命中」。

### 插件和工作流停在已发布的定义

适用问法：能力边界、工具边界、工作流边界、能不能顺便改生产、代码节点。

插件停在已归档定义：输入参数、输出结果、超时和它背后的 API。HiAgent 不在执行时给插件增加新的权限。插件返回什么，业务系统就是什么；插件超时或报错，业务动作就没有完成。

工作流停在已发布的图。它可以调用图里已经配置的知识库、插件、模型和代码节点，也可以在人工或中断节点停住，等恢复接口继续。图里没有的节点，这次运行不会临时长出来。

同步运行会等到本次执行返回。异步运行要再查状态，不能在刚提交时就把结果当成已经成功。

完成标准：外部副作用只归因到实际执行成功的插件或工作流节点，并保留运行状态。

### 会话身份停在应用密钥和工作空间

适用问法：权限、租户、工作空间、用户变量、身份、能不能看到别人的数据。

对话使用应用密钥，知识库检索使用工作空间 ID，观测使用工作空间 ID 加上火山引擎访问密钥。三套身份不要混用。

应用用户变量只对这个应用的这个用户有效。长期记忆也是。它们不会自动变成其他应用、其他工作空间或其他员工的可见数据。

Webhook 触发需要应用密钥、webhook key 和 webhook token。触发记录可以查询。没有这组凭证，就不能说 HiAgent 已经接上了某个外部事件。

完成标准：每次调用写明使用的应用或工作空间；跨空间、跨应用的数据访问标为当前身份不可用。

### 怎样判断一件事该不该交给 HiAgent

适用问法：该用 HiAgent 吗、做不到、边界判断、能不能实现。

用下面这张表判断：

| 要做的事 | 交给 HiAgent 的条件 | 超出 HiAgent 时 |
| --- | --- | --- |
| 回答一份已经入库的制度、手册、口径说明 | 应用已绑定对应知识库、问答库或术语库，检索返回了分段 | 改去源系统或先完成入库；检索为空就说明未命中 |
| 查询或变更数仓、调度、元数据、代码仓库 | 已有插件、MCP 或工作流节点连通该系统，并且本次执行成功 | 由该系统自己的接口完成，HiAgent 不内置这些引擎 |
| 按固定步骤跑通审批、人工确认、多系统调用 | 已发布工作流包含这些节点 | 先发布工作流；中断状态要等恢复，不算已完成 |
| 记住这个用户在本应用里的偏好 | 使用该应用的长期记忆或用户变量 | 企业主数据仍放在主数据系统 |
| 判断一次改动有没有变好 | 用评测任务和评测报告 | 报告不会自动发布新版本 |
| 排查智能体为什么慢或失败 | 用观测 Trace 的耗时、状态和 Token | 业务数据错了要查源系统和数据任务 |
| 保存一个附件 | 用上传服务 | 要被问答命中，还要进入知识库并可检索 |

完成标准：表格里能选出一行。条件不满足时，输出缺的是绑定、发布、执行成功，还是这件事本身不属于 HiAgent。
