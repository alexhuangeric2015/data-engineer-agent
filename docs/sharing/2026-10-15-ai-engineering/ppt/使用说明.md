# 交流演示稿使用说明

打开同目录的 `index.html`，无需安装或启动服务。39 页按约 90 分钟主讲组织，交流时间另计。

| 操作 | 快捷键 |
|---|---|
| 上一页 / 下一页 | ← / →，也支持滚轮和触屏滑动 |
| 全稿索引，点击跳页 | ESC |
| 当前页讲者备注与资料来源 | N |
| 完整讲者手册 | R |
| 进入 / 退出全屏 | F |
| 切换静态 / 动态模式 | B |
| 回到开头 / 跳到结尾 | Home / End |

备注会显示在当前演示窗口中；投屏时如需私下看备注，请在另一设备打开 `讲者手册.md`。

## 每页目录

- 左侧常驻完整章节目录；展开当前章的小节并高亮当前位置。
- 点击章节或小节可直接跳转；顶部显示章名、小节编号和小节名。
- 封面、观点页和收束页也保留目录。
- 同步恢复为贯穿教学案例，具体解释和输入示例可在 N 备注、R 手册查看。

## 建议时间

- 开场：3 分钟。
- 人的价值与新岗位：24 分钟。
- 方案、详细设计与 SKILL：31 分钟。
- Review、验证与放行：17 分钟。
- 工具与模型选型：8 分钟。
- 多智能体协同与收束：6 分钟。

## 演示与资料

- HTML 已内嵌内容、备注、样式与 Motion 动效，可单文件拷贝和离线演示。
- 在线字体不可用时自动使用系统无衬线字体，版面可能有轻微字体差异；外部资料链接需要网络。
- 默认静态呈现、即时翻页；B 可开启内容动效，翻页过渡为 160 毫秒。全稿统一纸白背景。
- 浏览器打印可生成横向逐页 PDF，打印前建议关闭浏览器页眉页脚、开启背景图形。
- 工具与模型页提供基于官方能力的试用建议，不宣称同条件实测排名；具体模型列表与额度以现场版本为准。
- 同步功能与重复写入故障是教学案例，不宣称为真实生产事故。

## 文件

- `index.html`：演示稿。
- `讲者手册.md`：逐页内容、展开提示、讨论问题与来源。
- `slides.json`：结构化内容。
- `项目记录.md`：模板、主题和版式记录。
- `验收记录.md`：本次检查范围与结果。
