# 字典知识库定位

## 职责

输入为原始问题、目标输出、已确认字段或类型范围、剩余定位额度。使用实际知识库检索工具，输出供 `dictionary-query-db` 核验的候选标识。直接字典问题无需表；有字段依赖时，必须已有结构 DB 核验的表和字段。

## 工作步骤

1. 用原名称、代码、值或描述及已有范围合并检索；本回合最多一次。字段 DB 给出的代码英文/中文名称作为定位条件，不按字段后缀推断类型。
2. 仅提取真实片段中的 `code_table_en_name`、`code_table_cn_name`、版本字样、`code_value`、`code_desc` 和简短依据。值与描述是定位线索，不作为最终答案；码值描述不能冒充字典定义。
3. 按类型标识整理候选，保留版本、名称冲突和各输入归属。每目标最多五个相关类型，不默认最新、最相似或第一个；标识缺失就注明，不生成代码。
4. 逐目标交还有候选待核验 / 标识不足 / 未召回 / 工具失败 / 上游未确认 / 额度用尽，附真实 KB 名、候选类型和值线索及缺口。

候选有可用中文名即可交 DB 精确核验；只有码值时提供原样值及明确上下文，由主流程决定精确反查范围。仍无法提供可执行的对象或值标识时收敛问题，不伪造条件。

## 结束

返回后即结束，不调用 DB 或其他 SKILL、不重新查表、不换词反复检索。未召回不证明字典不存在；命中不证明类型适用、字段引用或全量完成。用户选择候选后，主流程继续原始输出目标，不能只回答已定位。
