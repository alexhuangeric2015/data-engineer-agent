# 字典知识库定位

## 调用条件

接收主控六组任务记录及定位许可。独立字典/码值请求不要求表；字段关联请求先有 DB 核验且已确认的表字段，用其真实代码名称定位。上游未确认、已停止、无额度时交还原因，不调用。只使用绑定知识库，不调用 DB、结构工具或其他 SKILL。

原目标/范围或剩余额度不足以执行时回传待补信息及缺口，不自行猜测或调用。

## 工作步骤

1. 按原目标一次合批检索，保留原始名称、英文标识、指定值/含义、明确范围及字段代码名称；无类型的码值或含义反查保留原反查范围，不自行指定某类型。
2. 从片段提取实际出现的类型英文/中文名称、code_value、code_desc，保持类型—值配对及原字符串；标明精确或近似及实际出现的版本限定。
3. 同标识去重但保留冲突，优先返回每个定位目标至多五个相关类型候选；相似或版本接近不以 Top1、较新年份或常识代选。候选子集不证明原名唯一或反查完整。
4. 有相关可用标识则回传待核验；无召回/标识不足为定位终止；工具错误为查询失败；无额度为额度用尽。保持原成员枚举目标，不在定位成功后宣布问题完成。

## 完成与回传

按六组记录回传任务/阶段、状态及原因、实际 KB 片段/知识库来源、原范围与候选范围、完整性未知、实际调用数与缺口。本次没有新增 DB 证据，保留已有父对象的 DB 证据及确认状态。仅建议下一步核验，不能给真实类型存在性、实际绑定或完整码值结论。此次回传即结束，不再检索。

## 字段参考

字典线索对应 data_asset_code_kb 的 code_table_en_name、code_table_cn_name、code_value、code_desc。code_desc 是单一码值含义。字段输入的 related_column_en / related_column_cn 分别对应类型英文/中文名称，引用证据来自结构 DB，知识库不建立绑定。层级或父子关系仅保留明确出现的线索，不根据码长推断。
