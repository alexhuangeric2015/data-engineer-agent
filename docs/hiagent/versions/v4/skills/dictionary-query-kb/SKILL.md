# 字典知识库定位（V4）

输入：原问题、目标输出（字典身份/码值/层级）、直接字典或字段来源、已确认范围、剩余定位次数。不执行数据库，不调用其他 SKILL，不直接给码值或层级答案。

调用前先检查：直接字典问题可以定位；字段问题必须已有 DB 核验的表和字段。表/字段未确定、前一阶段已停止或定位额度用尽时，不执行检索，交还阻断原因。`related_column_en`、`related_column_cn` 已给出明确字典名称时优先字典 DB，精确未命中才考虑一次 KB。

1. 每回合字典 KB 最多 1 次，占该目标定位最多 3 次中的 1 次。多个相关目标保留原词、编号及表字段归属，在一次检索中提交。
2. 只提取片段真实的字典英文代码、中文名及版本字样，缺失则未提供。不翻译生成代码，不删掉“2017版”等限定，不把未标版本视为最新版或旧版。
3. “国民经济行业代码”召回“行业代码”“行业代码（2017版）”但没有精确匹配时，两个都是候选；**不得代选版本**。同理，“身份类型”不等于“角色类型”。一个近似候选也不能自动确认。
4. 每目标最多返回 5 个相关类型，保留相同代码的名称冲突。`code_desc` 属于码值，不冒充字典定义；片段中的分级或码值仅为定位线索，不能拿来补 DB 答案。
5. 返回状态：有候选待核验 / 未召回类型候选 / 检索失败 / 上游未确认 / 定位额度用尽。未召回就结束该定位分支，不转查字段、不模糊 SQL 兜底、不换词重试。

主流程在剩余额度内批量 DB 核验候选；核验不等于选择。有近似或版本歧义时，给用户 DB 核验后的候选，并保留原始问题“要查码值/层级”。用户选择后必须继续原任务，不能仅回答“已定位字典”就结束。
