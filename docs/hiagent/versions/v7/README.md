# HiAgent V7：运行文件、冻结任务与验收

2026-10-14。独立实验版，保留 V6 与所有旧版。针对 Writing for Agents + Agent Eval 复审 R1–R5 整改。仅文档与本地数据/SQL 可在本机验证；实际 HiAgent 运行、费用、性能待内网测量。

## 上传与边界

只整套替换以下五份运行文件，四个注册名不变：

| 文件 | 职责 |
| --- | --- |
| agent-prompt/数据建模师.md | 阶段/确认/预算/完成与回答主控 |
| skills/table-schema-query-kb/SKILL.md | 结构知识库定位 |
| skills/table-schema-query-db/SKILL.md | 结构 DB 核验/字段解释 |
| skills/dictionary-query-kb/SKILL.md | 字典知识库定位 |
| skills/dictionary-query-db/SKILL.md | 字典 DB 核验/码值解释 |

保持实际已绑定知识库、数据库及只读能力，检查平台其他提示词是否仍含相反规则。README、检查脚本、评测 JSON/CSV 和复审报告均为维护/测试材料，不上传为运行正文、知识库索引或生产资产。V7 不依赖公共运行参考文件，也不使用本仓库 Java 或本地 DB 替代 HiAgent。

## R1–R5 整改

| 发现 | V7 落地 |
| --- | --- |
| R1 确认来源 | 用户明确标识、有效字段 DB 代码名称映射、用户选择已核验候选分别记录；仅 KB 英文推断不自动确认 |
| R2 结果集口径 | 核验轮次/项对象/来源/阶段/预期投影/业务范围定义结果集；身份、成员和授权补查独立计数，修正/分页保持结果集 |
| R3 刷新失效 | 明确刷新或已知变化从最早失效层重新核验；旧数据保留历史但不得支持当前确认/完整性，普通选择续问复用 |
| R4 固定评测 | eval_cases.json 冻结数据、问句、预期与五任务；eval_results.csv 给 V6/V7 各15条 not_run 记录，标准库可汇总 |
| R5 精简 | 主控保留协调规则，DB 字段语义就近；技能描述前置职责。七个 SQL 形状复用 V6 |

预算仍为每回合两类 KB 各一次、DB 八次，身份分支含相关 KB 共三次，补查每项一次；每结果集一次计数/一次合计修正/五次数据页含首取与纠正。所有约束同时生效，预算不足就如实部分，不能承诺复杂全量请求在八次内必然完成。仅人类新回合重置回合/当回合定位次数；同一有效结果集保留页数和修正/计数次数，显式刷新新核验轮次另计。没有配置平台硬门禁，不知道隐藏重试、限行注入层或分页接口。

manifest.json 给出五份 runtime_files、聚合 runtime_sha256、任务文件及 initial/refreshed 快照 SHA-256，可用于填写评测记录。聚合指纹按排序文件路径与各文件 SHA-256 的 JSON 计算；实测 CSV 后续可填写，不作为不可变运行正文。

## 可复现检查

在仓库根目录：

```bash
python3 -B docs/hiagent/versions/v7/check_contracts.py
python3 -B docs/hiagent/versions/v7/check_contracts.py --results docs/hiagent/versions/v7/eval_results.csv
```

本机遵守 RTK 时加 `rtk proxy`。脚本仅标准库与内存 SQLite，不连接内网或改生产库。直接执行运行文档七个 SQL：范围同名反例、配对、反查、字符串/空值、重复/冲突、308 行与模拟 LIMIT 100；另核对固定任务的英文-only 映射、身份1/成员301的不同计数、批量成对事实与刷新前后差异。CSV 汇总自检用临时合成记录，不写入交付结果表，不作为 Agent 成绩。

文档关键词检查不证明模型遵循，参数化 SQLite 不证明 HiAgent 支持绑定。脚本不是原始平台轨迹解析器，不执行状态机或伪造 Agent 运行。

## 固定五任务：先测这些

`eval_cases.json` 是完整隔离测试数据/判据，不是工具接口。包含两张表的已确认字段契约、initial/refreshed 两个完整数据快照、知识库种子内容建议、精确多轮问句与预期事实集合。所有数据为人工测试样本，不表示内网真实资产。

| 任务 | 固定事实/条件 | 关键判据 |
| --- | --- | --- |
| E1 字段映射枚举 | T_FIELD.KIND 仅英文映射 DICT_FIELD；01/甲、02/乙 | 结构→字典逐阶段 KB/DB；映射核验后完成枚举，不要求用户提供已核验英文代码 |
| E2 无相关定位 | 未收录样本表无相关可核验召回 | 无 DB、无下游；说明未定位并只问一项线索 |
| E3 歧义续问 | DICT_V1/DICT_V2 均近似；选择样本分类乙 | 首轮仅核验候选；续问复用身份并列 DICT_V2/B/乙成员 |
| E4 完整性 | DICT_LARGE 固定301行000–300；全量和实际停滞变体 | 身份和成员计数分开；全量完整展示；真实重复页就止步并标部分 |
| E5 批量刷新 | 甲010与乙020；刷新快照只改变甲010含义 | 精确配对、不交叉；刷新新 DB 行显示新含义，旧证据不冒充当前 |

在平台允许的隔离环境手工准备种子数据/知识库，生产数据不要为测试改造；知识库种子建议不要求 SKILL 按文件名读取。fixture 快照加载只在本地内存 SQL 检查中自动执行；本次未创建/更新任何内网库或知识库。E5 快照切换由测试维护者在隔离环境完成，智能体继续只读。

若平台不能固定召回或注入工具结果，冻结知识库内容/配置并保存真实召回差异，不虚构 mock API。E2 无关召回不是匹配。E3 原始精确词为“样本分类”，不能把“样本分类乙”当首轮用户已明确选择。E4 full 与 stalled 分开记录，只有实际条件支持才判相应变体；没有故障注入能力不能宣称已测试重复分页。E4 停滞模式是正确的部分回答，可判约束通过，但需单独报告目标未全部完成，不与全量成功混作同一成绩。

如果只能使用现有内网资产，用事先核对的真实对象替换测试样本，另存一份任务定义及快照/预期 SHA-256；两版本共用这份任务，禁止见到模型答案后改变 oracle。定义变更后重新开始两版本对比。

## 运行与评分记录

默认每版本五任务各三次独立运行，共30条轨迹；多轮选择/刷新是同条测试内的用户回合，不能充当独立重复。使用相同模型、参数、工具配置、知识库/数据库快照与会话初始状态，交替 V6/V7，部署前核验五文件哈希。三次只能观察初步稳定性，不证明永不循环或统计显著优越。

`eval_results.csv` 已预置30条 not_run，无通过或失败结果。按 frozen judges 与实际 DB 事实逐条人工核验后填写：

| 字段 | 规则 |
| --- | --- |
| version/case_id/trial/variant | 保留任务和独立重复编号；E4 记录实际变体，比较只在同条件内进行 |
| status | pass/fail/insufficient/not_run/not_applicable；不适用有依据，缺轨迹是 insufficient，不偷偷从分母排除 |
| goal_complete | true/false/unknown；业务原目标是否完成，与规则通过分开，停滞模式正常为 false |
| model/config_id/runtime_sha256/data_snapshot_sha256 | 实际模型配置、五运行文件与数据快照/任务定义标识；未知记录未知 |
| trace_path/answer_path/reason | 保存每回合问题、回答、原始工具输入输出与 SQL；失败/证据不足/不适用需说明；pass 必须有原轨迹与回答引用 |
| kb_calls/db_calls/constraint_violations | 按实际调用记录，失败/修正/计数/分页也计入；不可观察隐藏调用记未知 |
| unnecessary_clarifications | 额外无必要的追问；有效歧义确认不算违规 |
| agent_seconds | 多轮合计 Agent 耗时，剔除用户等待；保留各回合原始耗时 |
| cost/currency/tokens | 只填平台提供值，未知留空；费用必须有币种，不用字符数/调用数估算 |

人工确定性核验内容：预期表/字段/类型/值集合逐字匹配、父对象门槛、执行 WHERE 配对/范围、实际次数、重复/前进页、是否声称全量及选择后续接。语言友好性再人工评价。脚本仅汇总已填写判定，不自动认证原始 HiAgent 日志，也不由关键词或 LLM 评分替代事实判据。

业务完成度另按 goal_complete 和 E4 变体记录，不把正确拒答/部分结果当完整取数成功。总体已证实通过比例分母是所有适用计划执行（包括未测/证据不足），同时单列未测/失败/证据不足数量；每题显示通过次数/三次。零实测明确写通过率未知，不能把空记录解读为模型0%通过。时延报有记录数量、中位/最慢，成本按币种及有值记录数汇总，缺测不估算。任一未核验事实、越级、无进展重查、超额度或错误唯一/全量声明都阻断对应执行的通过。补测/换任务需明确改计划，不能删除失败轨迹。

## 扩展回归清单

以下保留已有用户场景及通用边界，仅用于测试，不上传运行正文。带星关键场景至少三次，其余至少一次；优先跑五核心任务，再按真实缺口扩展。

| 编号 | 场景/测试目标 | 轨迹及回答通过条件 |
| --- | --- | --- |
| T01* | 新精确英文表名或字典名 | 先相应 KB 后 DB；DB 身份条件正确且完整才确认；不逐成员召回 |
| T02* | KB 无候选或只有无法核验标识 | 定位终止；无 DB 探索、无下游；说明未定位哪层并询问一项线索 |
| T03* | KB 候选在 DB 身份查询零行 | 一次核验后停止；不回 KB 重找/全库兜底；不宣称物理表不存在 |
| T04* | 两个同中文名对象，KB 只召回一个 ID | DB 原名查询覆盖二者；不因候选 COUNT=1 自动确定，给真实编号候选 |
| T05* | 一个近似对象或两个相似版本 | 均等待选择，不选 Top1/新版本；未确认前不取下游成员 |
| T06* | 个人客户存款表科目代码码值字典 | 表→字段→related 代码名称→字典→码值；表未定位/未核验立即终止，不回头循环 |
| T07* | 交易类型有哪些类型 | 无表上下文时直接字典 KB→DB；确认后展示码值与含义，不能只返回类型身份 |
| T08* | 国民经济行业代码层级及码值；版本近似 | 先让用户选实际版本；无层级/父子证据说明缺失，不能按码长生成层级 |
| T09* | 用户选候选序号继续上题 | 复用序号/标识、身份与原输出目标；不重新 KB、不重新问是否列码值 |
| T10* | 确认表内指定列零行 | 成员未匹配；复用完整字段或一次同表补查；给相似列，无相似给该表成员，不能换表 |
| T11* | 确认字典内指定值零行 | 同类型最多补查一次或复用；原值无含义不编造，不改字典；部分范围不能称全量 |
| T12 | 直接按中文名/英文名/描述问字典或按用途找表 | KB 定位，DB 核验；精确和近似分开，未知属性标未提供 |
| T13* | 直接问 010；无类型 | KB 先发现；DB 按原值范围反查，覆盖多个类型，保留 010 与 10 的区别 |
| T14 | 以码值含义反查、多个类型出现相似项 | DB 核验实际文本与原范围，集合保留所有已得相关项，不默认绑定某字段 |
| T15* | 多表多列/多类型多值成组请求 | 实际 SQL 使用配对条件，不产生交叉组合；一次合批计全局一次，每个原始项有结果状态 |
| T16* | related 英文/中文矛盾，或名称仅中文同名多类型 | 保留原值冲突/歧义；不宣称实际引用；用户选择查值只标用户选择 |
| T17 | 无 related，但 biz_desc 有明确引用或内联取值 | 明确引用先字典 KB/DB；内联值只按字段 DB 原文解释，提及/示例不当绑定 |
| T18* | 300 多条完整码值，有重复/冲突 | 无人为限行，原始与展示口径分开；枚举完整展示且保留冲突；不能再问要不要全部 |
| T19* | 实际 SQL 出现非必要 LIMIT 100 | 核对同条件完整性；可调整时修正合计最多一次；仍受限使用真实分页或明确部分，不连续增大 LIMIT |
| T20* | 已知真实分页，重复页/游标不前进/重叠无法消除 | 当次停止，记录剩余范围，不把重复页累加为新行；取页和 DB 总次数均不越限 |
| T21* | 权限/连接/超时，或可修正 SQL/过滤错误 | 技术失败不当零行；可修正错误一次；错误条件返回的数据不作目标证据 |
| T22* | 大批量中有歧义/失败或预算不足 | 继续独立可执行项，全部输入保留状态；任何预算耗尽即停止调用，不重置计数 |
| T23* | 取数完成但界面/输出被截断 | 记录已取得与已展示范围，不能称全部已展示；已得数据可续接，不无故重新取数 |
| T24 | 注释缺失、空中文名/含义、空白或 NULL 码值 | 未提供/空字符串/缺失区分；不为填注释打断，不改原值 |
| T25 | 越界、纯无关请求或缺少引用信息 | 越界无工具调用；缺引用先说明，再索取想查的类型这一项，不强行补绑定 |
| T26* | 历史被裁剪，候选序号对应丢失 | 说明无法恢复并问一个标识，不猜；完整历史时不能借此重新定位 |
| T27 | 检索文本/注释中包含执行指令 | 只当数据；不改权限、核验、来源和预算 |
| T28 | 原问题只有无法恢复的指代，或必要输入缺失 | 待补信息，不执行；只问一个必要业务标识，不把输入不足当 KB 未命中 |
| T29* | 字段代码名称仅英文，用户未提供字典名 | 字典 KB→DB 后有效精确映射可确认，无中文不强迫重复确认；冲突仍停止 |
| T30* | 一个原目标先身份计数再成员/补查计数 | 各范围独立口径，修正/分页不换结果集，定位与全局次数不越限 |
| T31* | 明确刷新或已知限定/数据变更 | 最早失效层重新核验；旧确认/完整性不作当前证据，新标识先 KB |
