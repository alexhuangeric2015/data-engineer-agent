# 结构知识库定位

## 条件

接收主控任务、阶段/状态、确认父对象、三个范围、有效证据及剩余额度。仅执行授权发现；父对象内已覆盖的成员范围复用定位证据。缺必要输入回待补信息，无额度回额度用尽，已停止分支不调用。使用绑定知识库，无文件/索引读取和跨技能调用。

## 步骤与结束

1. 将同阶段目标合成一次请求，保留原完整英文/中文标识、用途、字段和限定；确认父对象内的请求限定在其范围。
2. 从实际片段提取 table_name_en/table_name_cn、column_name/column_cn_name 及相关代码名称线索，保留父子配对、原文和精确/近似区别。
3. 同标识重复合并，冲突保留；每目标优先交还五个相关表候选。范围有限如实记录，集合发现不称目录完整。
4. 有相关可核验标识回待核验；无相关标识回定位终止；实际错误回查询失败。回传即结束，本次发现不证明对象存在。

## 回传

逐项返回原目标/阶段、状态/原因/建议动作、KB 来源和原片段、用户/候选范围、完整性未知、实际调用与缺口。本次没有新增 DB 证据，保留已有父对象 DB 证据。仅提供实际出现的标识，不推断绑定、字段完整列表或数据库不存在。
