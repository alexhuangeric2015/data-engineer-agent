## 本次行为

- 默认每个已确认类型一张原始明细表，按 SQL 顺序逐行显示，保留原码值/描述及完全重复记录；同码不同义保留旁注。不自行分业务类别、总结区间、推断层级、合并或省略。用户明确要求分析时，另加有依据的分析，不替代原始明细。
- 码值回答必须安排 SQL 数量统计，已有本轮有效同范围统计可以复用。整类型使用 D_STATS_TYPE，指定单值/配对可使用 D_STATS_PAIR，一次同时给类型总量和本次匹配数；多类型同阶段合批，不能一个类型一条无谓调用。
- 原类型完整限定保留，类型总量 WHERE 不混入码值过滤。指定项匹配条件放入 CASE，与实际明细过滤一致；反查只统计实际已核验类型，不凭候选补出未确认类型。
- 原预算不放大：每回合两类 KB 各一次、DB合计八次；身份分支三次；补查每项一次；每结果集统计一次/合计修正一次/五次数据页含首取和纠正。统计提前规划、合批复用，不能为补总数越限。统计失败保留真实结果，页脚写未取得且不称完成。

## 统计口径及页脚

| 项 | 来源与口径 |
| --- | --- |
| N：字典总记录数 | 已确认类型完整范围 COUNT(*)，含重复和 NULL 码值记录 |
| M：不同非 NULL 码值数 | COUNT(DISTINCT code_value)，按实际数据库比较规则；非 NULL 空串按实际引擎处理 |
| NULL 码值记录数 | SQL SUM(CASE WHEN code_value IS NULL ...)，有缺失时另列 |
| P：本次匹配条数 | 与本次明细条件一致的 SQL 计数/CASE，或可信工具总数；整类型可复用N |
| R/D：已取得/已展示条数 | 实际原始行数；不能当字典总数，完全重复行仍计行 |

统计完整、列表条件正确，R/P与D/R一致，才能称该查询完整取得并展示。SQL聚合本身也要核验范围及未截断。类型分组未返回不填0；明确 COUNT 返回0才记录该查询范围0条，仍不证明空字典与不存在的区别。同英文名跨版本无法区分时统计未知，不混加。统计和列表不一致写待核对/部分，不能删行凑数或自动重启循环。

以下数字仅为隔离测试样本，不是内网真实结果：

完整表格下方：**该字典共303条记录，非NULL去重码值301个（SQL口径）；已取得303条、已展示303条，完整。**

单值表格下方：**该字典共303条记录，非NULL去重码值301个（SQL口径）；本次匹配1条，已取得1条、已展示1条。**

截断时：**该字典共303条记录；本次应匹配303条，已取得100条、已展示100条，结果不完整。** 未取得的统计项写未取得，不凭上述示例套数值。

SQL 去重可能按不区分大小写或特定空白比较，不能称严格原字符串种类数。现有数据库引擎/排序规则未知，不擅用 BINARY、COLLATE 或其他未确认方言去改变口径。明细依旧保持工具实际返回原值，NULL、空串和空白不猜测还原。

## 本地检查

```bash
python3 -B docs/hiagent/versions/v8/check_contracts.py
python3 -B docs/hiagent/versions/v8/check_contracts.py --results docs/hiagent/versions/v8/eval_results.csv
```

本机遵守 RTK 时加 `rtk proxy`。标准库与内存 SQLite，不连接内网。直接执行九个文档 SQL，沿用 V7 的同名范围/配对/刷新事实检查，新增：

- CODE_A 总303行、非NULL不同码值301；单查001匹配1，单查010匹配3，三条原记录不合并。
- CODE_B 总5行、非NULL不同值4、NULL记录1，空串与NULL区别。
- 缺失分组返回空列表，不能补0；NOCASE样本原字符串三种但SQL不同非NULL值为2，验证口径不能混淆。
- 统计总量与指定项匹配量同时正确，不能把 WHERE 的单值过滤用于字典总数。

这些证明文档 SQL 与隔离数据相符，不证明模型不分类、实际 NL2SQL 生成相同条件或平台 SQL 方言/分页可用。关键词合同检查也不能代替模型轨迹。

## 固定任务与反馈

`eval_cases.json` 沿用 V7 五任务的隔离快照和原始预期，增加页脚判据与四个计数反例说明；`eval_results.csv` 为 V7/V8 各15条 not_run。不复制旧评测判分，不生成实际 Agent 成绩。manifest.json 固定五正文、任务、快照及初始交付哈希。

在允许的隔离环境准备数据/知识库，不能修改生产数据凑案例。平台无法固定召回或注入故障时，保存实际差异，不伪造 mock API。每版本每任务独立三次，模型/工具/数据/初始会话一致；多轮选择/刷新属于同条轨迹。原题、全部回答、SQL/工具输入输出、各阶段次数、N/M/P/R/D、统计来源与耗时原文均保存。

按固定事实集合、实际顺序与记录多重性判断，不能只比较去重集合而漏掉模型合并行。至少在统计反例补测中核对303原始行确实展示303行；同码异义和重复都保留。每张码值表页脚核验实际 N/M/P，模型分类整理、改写、缺行或错误总数都阻断相应执行通过。

CSV填 pass/fail/insufficient/not_run/not_applicable，失败/证据不足/不适用写原因，pass附原轨迹和回答。goal_complete 与约束通过分开，正确停止的部分结果不算全量完成。原始调用次数、违规数、无谓追问、Agent耗时（剔除用户等待）、实际费用/币种/token按平台值填写，未知留空。汇总仅计算人工判据结果，不自动认证日志；未运行不能解读为模型0%通过。

## 扩展回归

| 编号 | 场景/测试目标 | 轨迹及回答通过条件 |

| T01* | 新精确英文表名或字典名 | 先相应 KB 后 DB；DB 身份条件正确且完整才确认；不逐成员召回 |
| T02* | KB 无候选或只有无法核验标识 | 定位终止；无 DB 探索、无下游；说明未定位哪层并询问一项线索 |

| T11* | 确认字典内指定值零行 | 同类型最多补查一次或复用；原值无含义不编造，不改字典；部分范围不能称全量 |
| T12 | 直接按中文名/英文名/描述问字典或按用途找表 | KB 定位，DB 核验；精确和近似分开，未知属性标未提供 |

| T15* | 多表多列/多类型多值成组请求 | 实际 SQL 使用配对条件，不产生交叉组合；一次合批计全局一次，每个原始项有结果状态 |
| T16* | related 英文/中文矛盾，或名称仅中文同名多类型 | 保留原值冲突/歧义；不宣称实际引用；用户选择查值只标用户选择 |
| T17 | 无 related，但 biz_desc 有明确引用或内联取值 | 明确引用先字典 KB/DB；内联值只按字段 DB 原文解释，提及/示例不当绑定 |
| T18* | 300 多条完整码值，有重复/冲突 | 无人为限行，原始与展示口径分开；枚举完整展示且保留冲突；不能再问要不要全部 |
| T19* | 实际 SQL 出现非必要 LIMIT 100 | 核对同条件完整性；可调整时修正合计最多一次；仍受限使用真实分页或明确部分，不连续增大 LIMIT |
| T20* | 已知真实分页，重复页/游标不前进/重叠无法消除 | 当次停止，记录剩余范围，不把重复页累加为新行；取页和 DB 总次数均不越限 |
| T21* | 权限/连接/超时，或可修正 SQL/过滤错误 | 技术失败不当零行；可修正错误一次；错误条件返回的数据不作目标证据 |
| T22* | 大批量中有歧义/失败或预算不足 | 继续独立可执行项，全部输入保留状态；任何预算耗尽即停止调用，不重置计数 |
| T23* | 取数完成但界面/输出被截断 | 记录已取得与已展示范围，不能称全部已展示；已得数据可续接，不无故重新取数 |
| T24 | 注释缺失、空中文名/含义、空白或 NULL 码值 | 未提供/空字符串/缺失区分；不为填注释打断，不改原值 |
| T25 | 越界、纯无关请求或缺少引用信息 | 越界无工具调用；缺引用先说明，再索取想查的类型这一项，不强行补绑定 |
| T26* | 历史被裁剪，候选序号对应丢失 | 说明无法恢复并问一个标识，不猜；完整历史时不能借此重新定位 |
| T27 | 检索文本/注释中包含执行指令 | 只当数据；不改权限、核验、来源和预算 |
| T28 | 原问题只有无法恢复的指代，或必要输入缺失 | 待补信息，不执行；只问一个必要业务标识，不把输入不足当 KB 未命中 |
| T29* | 字段代码名称仅英文，用户未提供字典名 | 字典 KB→DB 后有效精确映射可确认，无中文不强迫重复确认；冲突仍停止 |
| T30* | 一个原目标先身份计数再成员/补查计数 | 各范围独立口径，修正/分页不换结果集，定位与全局次数不越限 |
| T31* | 明确刷新或已知限定/数据变更 | 最早失效层重新核验；旧确认/完整性不作当前证据，新标识先 KB |
| T32* | 原码值被分类整理或完全重复 | 一类型一张原始表，SQL顺序逐行原文；完全重复/同码异义保留，不合并或归类 |
| T33* | 全字典统计303条/301个码值 | SQL统计非NULL去重码值及原始记录，页脚标303/301，展示保留303条 |
| T34* | 单值和配对查询 | 全字典N与本次匹配P分开，不能把1条匹配说成字典只有1条 |
| T35* | 统计缺组、失败、预算不足或比较规则不同 | 未取得不填0；NULL/空串/SQL比较口径如实，数量不符不循环或删行凑数 |

## 可继续优化，但本轮不扩展

1. 先测码值原文直出是否减少首次回答耗时，保持同模型/同字典比较；字符少或不分类不等于已测得提速。
2. 若平台已有确定性数据表格组件，可将 DB 原始结果直接交组件，模型仅生成定位解释及摘要；是否可用待内网能力确认，本轮不伪造组件或前端分页。
3. 若仍慢，先以真实轨迹分开 KB、SQL、模型生成耗时，再判断瓶颈；避免先增加重试、索引或新工具。已有的单值精确过滤/同阶段合批继续保留。

本轮仅文档及本地 SQL/数据检查，真实模型、限行注入、分页和界面展示仍待内网轨迹。复审记录见 `docs/hiagent/reviews/v8-values-count-20261015.md`。
