# 字典知识库定位

本文件是 data-asset-query 的按需参考，不是独立注册 SKILL。按总入口已确定的阶段、证据及额度执行，记录结果后由总入口决定继续或结束。

## 阶段前置条件

使用总入口任务记录及发现许可。独立字典/码值入口无需表；字段入口先有有效结构 DB 证据与已确认表字段，使用其代码名称。有效父对象内成员复用定位证据。必要输入缺失回待补信息，无额度回额度用尽；上游未确认/已停止时不调用。仅使用绑定知识库，由总入口决定下一阶段。

## 定位步骤与阶段结束

1. 按真实检索参数将同阶段目标尽量合批，保留各目标原名称、英文代码、值/含义及限定；无类型反查保留原范围，字段入口带有效映射。没有独立多查询能力时，不把拼接字符串称为各目标均已覆盖；记录实际召回属于哪些目标，未覆盖项说明缺口，仍遵守总入口次数限制。
2. 从实际片段提取 code_table_en_name/code_table_cn_name、code_value/code_desc，保留类型—值配对、原字符串及实际版本，标明精确/近似。
3. 每目标优先返回五个相关类型，同标识重复合并、冲突保留。近似或版本接近只作候选；候选子集不证明原名唯一或反查完整。
4. 有相关标识回待核验；无相关可核验标识回定位终止；实际错误回查询失败。保持原枚举目标，记录后结束，本次定位阶段不再检索。

## 阶段结果记录

逐项返回目标/阶段、状态/原因/建议、KB 来源与原片段、用户/候选范围、完整性未知、实际调用与缺口。本次没有新增 DB 证据，已有父对象证据保持。真实存在性/引用和完整成员均待 DB 核验；只有 KB 英文线索不产生自动确认资格。
