# 结构知识库定位

本文件是 data-asset-query 的按需参考，不是独立注册 SKILL。按总入口已确定的阶段、证据及额度执行，记录结果后由总入口决定继续或结束。

## 阶段前置条件

使用总入口任务、阶段/状态、确认父对象、三个范围、有效证据及剩余额度。仅执行授权发现；父对象内已覆盖的成员范围复用定位证据。缺必要输入回待补信息，无额度回额度用尽，已停止分支不调用。使用绑定知识库，不读取业务知识库索引或指定知识文件。

## 定位步骤与阶段结束

1. 按真实检索参数将同阶段目标尽量合批，保留各目标原完整英文/中文标识、用途、字段和限定；确认父对象内请求限定在其范围。没有独立多查询能力时，不把拼接字符串称为各目标均已覆盖；记录实际召回属于哪些目标，未覆盖项说明缺口，仍遵守总入口次数限制。
2. 从实际片段提取 table_name_en/table_name_cn、column_name/column_cn_name 及相关代码名称线索，保留父子配对、原文和精确/近似区别。
3. 同标识重复合并，冲突保留；每目标优先交还五个相关表候选。范围有限如实记录，集合发现不称目录完整。
4. 有相关可核验标识回待核验；无相关标识回定位终止；实际错误回查询失败。结束当前阶段，本次发现不证明对象存在。

## 阶段结果记录

逐项返回原目标/阶段、状态/原因/建议动作、KB 来源和原片段、用户/候选范围、完整性未知、实际调用与缺口。本次没有新增 DB 证据，保留已有父对象 DB 证据。仅提供实际出现的标识，不推断绑定、字段完整列表或数据库不存在。
