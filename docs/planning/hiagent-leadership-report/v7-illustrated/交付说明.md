## 本次纠偏

PPT和draw.io分别设计，不再把汇报页直接转换为详细架构图。两者统一内容口径，分别满足讲述和架构审阅需要。

- 全景图回到用户认可的V0.3：保留六层主体、九类专业角色及职责、Agent内部运行机制、HiAgent支撑列、贯穿保障列、存量治理过程和底部血缘调用链。
- 全景只更新第06层“系统与平台”、相关平台分工和版本日期。已逐对象验证，238个对象的位置、分组、样式和连线与V0.3一致。
- 独立图集继承V0.3/V0.4的画布与模块表达，补充完整的模型、内容供给、指标、集成、部署、收益和在线数据流等视图；不再压缩为PPT同尺寸页面。
- PPT参考本轮示例，增加原生立体模块图示、架构主视觉、蓝白分区与橙色标题提示，重做封面、总体方向、场景收益、案例和指标价值等页面。
- 四类场景使用“处理链路＋解决问题＋应用价值”，让步骤、支撑事实和收益同时可见。

## 内容边界

保留30页规划内容，不设置技术备答或预算测算。当前仅建设资产智能体，其他能力为规划。任务规划与资源调用属于专业Agent，SKILL只提供方法。知识定位候选、外部资产查询库核验事实；实际血缘仍经数据资产平台获取。指标能力优先复用既有平台，部署采用逻辑视图。

立体图示为自制原生可编辑几何，不采用整页生成图片，也不复制示例中的品牌、SQL、产品名称或宣传数字。公开案例沿用此前核验资料，效果不外推为本项目承诺。PPT能力地图用于总览，完整全景的职责细节保留在独立draw.io中。

图集每张提供draw.io、SVG与3600像素宽PNG。PPT的文字、立体图形和连线均可编辑。历史版本及正式项目方案保留。
