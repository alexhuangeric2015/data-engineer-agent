页面应表达五段机制，不写成工具清单：

1. 变化感知：对接大数据与资产平台，监控模型、血缘、指标、术语等变更；血缘按现有接口形态适配（xlsx/图），不能假定已有完整字段级机读服务。  
2. 元数据健康探查：检查完整性、责任人、描述、术语/指标关联、映射一致性等（借鉴 Purview Metadata Quality / Health Controls：规则 → 发现 → 行动项与严重级别）。  
3. 质量规则落地：可复用检查定义应用到具体资产与字段（借鉴 OpenMetadata Test Definition / Test Case / Test Suite 分层）。  
4. AI Agent 与人工协作：Agent 生成候选补全、冲突说明与证据包；权威修改必须责任确认，不自动覆盖资产平台权威定义。  
5. 发布供给与回归：确认结果进入 HiAgent 知识库、查询库、指标库、术语库，并做检索/核验回归；与第16页内容供给数据流衔接。
