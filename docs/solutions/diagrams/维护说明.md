## 修改与同步

1. 优先修改正式多页图集。单页 draw.io 文件是对应页面的当前副本，修改后同步保存。
2. 泳道左右并列、顶部和底部对齐；泳道内按信息归属组织。功能架构表达功能归属，数据流程表达执行顺序。
3. 双击编辑文字，连线保持吸附端口。移动分区时选择父容器，让子节点一起移动。
4. 导出当前页 PNG 时使用白色背景，建议宽度至少 2400 像素，检查字号、换行、边距和连线。
5. 更新本目录对应 PNG，检查 Markdown 引用。后续方案默认仅交付 Markdown，不自动生成 Word 或更新旧交付包。
6. 五类图均为方案必需内容；内容不符时修正图源及展示图，保留正文中的相应视图。

## 历史版本

`方案图集-内容修订前.drawio` 保留本轮修订前页面；`总体与技术架构-前后对比.drawio` 保留此前的布局比较。历史更新流程及其单页文件不属于当前正式图集，也不在当前 Markdown 中引用。

## 内容边界

主提示词、查询 SKILL 和内容加工程序属于本期建设成果。内容更新表述为可配置能力。数据关系图表达逻辑映射，具体字段含义与查询结果对应。
