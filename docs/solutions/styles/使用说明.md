# 长行方案样式使用说明

正式正文为上级目录的 `数据资源智能体建设方案.md`，样式为本目录的 `长行方案.css`。

Markdown 本身不固定字体、字号及颜色。请在支持自定义 CSS 的 Markdown 阅读器中加载样式，或在 Markdown 转 HTML 时引用该样式。直接打开 Markdown 时，显示效果由阅读器决定。CSS 不会自动转换成 Word 的文档样式。

样式采用黑色加粗标题、深蓝正文、首行缩进、深灰底白字表头和黑色表格边框。标题黑体、正文宋体及字号、行距均为可调整的建议默认值，尚未由正式模板参数确认；本机没有相应字体时会使用字体列表中的后备字体。

分享时将 Markdown、`diagrams/` 和 `styles/` 一起复制并保留目录结构。配图和 draw.io 源图在正文中均使用相对路径。

本轮仅更新 Markdown 与样式，Word 仍是历史版本。如需 Word，应从最新 Markdown 重新转换，并应用对应的 Word 标题、正文、表格和分页样式。
