## 修改与同步

1. 建议以多页图集作为唯一维护源；单页 `.drawio` 文件是当前版本的独立副本。
2. 泳道保持左右并排、顶部和底部对齐，不改成上下逐行布局。双击修改文字；拖动节点时让连线继续吸附在节点端口。移动分区时选中容器，可连同子节点一起移动。
3. 保持统一配色：蓝色用于入口与智能体，绿色用于处理，黄色用于知识和数据，紫色用于规则，红色用于失败回退。
4. 修改后检查连线方向、分支文字、容器边界和换行。通过“文件 → 导出为 → PNG”导出当前页，建议宽度至少 2400 像素、白色背景并保留边距。
5. 将对应 PNG 更新到本目录，并在 Word 中右键对应图片，选择“更改图片”，保留原有宽度和题注。Word 中嵌入的是展示图片，图形对象请在 `.drawio` 源文件内维护。
6. 若继续保留单页源文件，通过“文件 → 导出为 → XML”只导出当前页，覆盖对应编号文件，避免多份来源内容不一致。

## 内容边界

图集描述建设方案，不代表所有能力均已部署。数据关系图仅表示逻辑映射，不表示物理外键；部署版本、调度与身份接入等仍以现场确认结果为准。
