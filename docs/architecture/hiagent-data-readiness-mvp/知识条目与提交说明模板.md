# 知识条目与提交说明模板

日期：2026-10-21。以下为收集和整理格式，不是 HiAgent 提示词或专有导入协议。尖括号内容由责任方补充；未确认字段保留待确认。条目正文可进入知识检索，正式定义仍需核验来源与版本；不依赖按文件名定向读取，也不新建知识库索引文件。

## 一、发给试点系统的资料提交说明

> 以下文字供项目负责人修改并自行发送；本轮未向任何人发送。

本次围绕〈业务域〉的〈报表/指标场景〉开展 HiAgent 数据研发辅助验证，范围为〈系统、相关表与指标〉。

请指定业务口径负责人、系统研发联系人、平台运维联系人。首轮请提供：

1. 该场景已有的报表样张、需求/制度说明及计算口径。
2. 相关表结构、字段说明、字典码值和已知关联关系。已有导出可直接提交，不需重抄。
3. 现有加工SQL、报表SQL或计算Excel，并注明目标引擎、版本与已知限制。
4. 一组获准的脱敏或虚构输入样本，以及业务认可的预期结果或对账依据。
5. 可用测试环境、只读权限和接口联系人；凭据按原流程管理，不填写在收集表中。

项目组负责预填模板并整理关键缺口，业务方确认术语和口径，研发确认字段和实现，平台方确认接入条件。没有模型库、术语库或指标库时，提供现有材料即可，不要求先建设对应平台。请于〈双方约定日期〉提交原始资料；关键问题由〈口径裁决人〉协调确认。

## 二、通用知识条目

### 条目元信息

| 字段 | 待填写内容 |
|---|---|
| 条目ID | 〈稳定ID，与结构登记保持一致〉 |
| 标题与别名 | 〈标准名称；近义但不同定义单独说明〉 |
| 类型 | 〈术语/指标/规范/案例/故障手册〉 |
| 适用范围 | 〈业务域、系统、对象及必要引擎版本〉 |
| 定义版本与有效期 | 〈版本；生效/失效时间，未知留空并登记问题〉 |
| 治理状态 | 〈草稿/待确认/已确认/冲突/已失效〉 |
| 原始依据 | 〈文件、页节、SQL版本、平台记录或查询证据〉 |
| 维护与确认 | 〈维护人；确认人；确认时间及记录引用〉 |
| 可访问范围 | 〈经原流程批准的组织/角色范围〉 |
| 关联对象 | 〈术语、指标、表字段、规则或作业ID及版本〉 |

### 定义和使用边界

- 业务定义：〈该对象到底表示什么〉。
- 包含范围：〈明确属于该定义的情形〉。
- 排除和反例：〈容易混淆但不属于该定义的情形〉。
- 业务例子：〈虚构或已获准脱敏例子，不能代替正式定义〉。
- 与相近对象的区别：〈同名异义、跨部门或版本差异〉。
- 待确认事项：〈未定内容及责任人，不能用模型推断补成事实〉。

建议一个条目聚焦一个定义或规则；定义、适用范围、例外、来源和版本应尽量被共同检索到。实际切分与召回通过平台命中测试验证，不能仅凭文件组织保证。

## 三、指标口径条目

沿用通用元信息，另填：

| 业务口径 | 内容 |
|---|---|
| 业务目的和统计对象 | 〈解决哪个问题，统计哪些对象〉 |
| 输出粒度和维度 | 〈每行结果代表什么；允许按哪些维度分析〉 |
| 计算公式 | 〈求和、去重人数、比率或复合依赖；比率分别定义分子分母〉 |
| 时间规则 | 〈业务时间、时区、日切、窗口边界及迟到处理〉 |
| 纳入与排除 | 〈状态、范围、退款、撤销、补录等〉 |
| 单位与可加性 | 〈单位、币种；是否允许跨日或维度加总〉 |
| 空值和例外 | 〈NULL、0、零分母、缺失及异常值的具体处理〉 |
| 验收依据 | 〈小样本输入、正确输出、对账报告引用及认可责任人〉 |

技术映射另列：〈来源表字段ID、字典码值、关联条件、去重、表达式、SQL引擎、代码版本、实际测试结果〉。对业务描述和SQL实现的差异建问题单，不静默覆盖其中一方。大段SQL作为受控附件，保留引用与版本。

## 四、分层和建模规范条目

沿用通用元信息，另填：

- 企业分层定义：〈ODM/CDM/FDM/PDM各层职责、允许输入输出、禁止边界〉。
- 建模粒度与命名：〈业务过程、事实/维度、主键、字段命名和中文说明〉。
- 历史处理：〈覆盖、快照、拉链等适用条件与例外〉。
- 生命周期：〈分区、保留期、清理、重算窗口及批准方式〉。
- 校验规则：〈可程序检查的规则及开放性评审项分别列出〉。
- 正反案例：〈符合/不符合规范的最小例子及原因〉。

不能从层名自动推断客户分层职责；规范未定时，产物标草稿，不承诺自动判层正确。

## 五、故障处置条目（后续运维试点）

沿用通用元信息，另填：

- 故障触发：〈真实错误特征、引擎/调度版本和日志证据〉。
- 必查证据：〈实例、输入分区、上游状态、资源情况〉。
- 适用条件：〈哪些情况下判断成立，哪些情况下不得套用〉。
- 建议动作：〈定位、重试、补数或配置调整步骤〉。
- 动作边界：〈权限、幂等、最大次数、影响范围及回滚〉。
- 成功判据：〈原任务状态与业务结果都需要哪些证据〉。
- 升级条件：〈何时停止自动处置，交给哪类责任人〉。

处置手册提供方法依据，不能充当某次生产执行授权。
